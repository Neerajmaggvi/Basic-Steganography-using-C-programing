# Basic Steganography Using C

A basic **Steganography project implemented in C** that demonstrates how secret information can be hidden inside the Least Significant Bits (LSB) of data.

The main purpose of this project is to understand how **bitwise operators, binary representation, and LSB manipulation** can be used to encode and decode information.

---

## 📌 What is Steganography?

**Steganography** is the technique of hiding secret information inside another form of data without making the hidden information obvious.

In this project, the basic idea is to hide the bits of a secret character inside the **Least Significant Bit (LSB)** of other data.

For example:

```text
Secret Character: A

ASCII value:
A = 65

Binary:
01000001
```

Each bit can be stored in the LSB of another byte.

## 🧠 Basic Concept

The project uses the **LSB technique**.

Suppose we have:

```text
Original data:

10110110
```

To store one bit of secret information, only the LSB is modified.

For example, if the secret bit is:

```text
1
```

The modified data becomes:

```text
10110111
```

Only the last bit is changed.

Similarly, if the secret bit is:

```text
0
```

The modified data becomes:

```text
10110110
```

This allows information to be hidden while making only a very small change to the original data.

## 🔐 Encoding

During encoding:

1. Take the secret character.
2. Convert the character into its binary representation.
3. Extract each bit from the character.
4. Store each bit in the LSB of the selected data.
5. Repeat until all 8 bits of the character are stored.

Example:

```text
Character = A

ASCII:
65

Binary:
01000001
```

The bits are processed individually:

```text
0 1 0 0 0 0 0 1
```

Each bit can then be stored in the LSB of another byte.

---

## 🔓 Decoding

During decoding:

1. Read the data containing the hidden information.
2. Extract the LSB from each byte.
3. Store each extracted bit in the corresponding position.
4. Reconstruct the original 8-bit character.
5. Display the decoded character.

The basic bit extraction operation is:

```c
bit = buffer[k] & 1;
```

Here:

```text
buffer[k] → selected data
& 1       → extracts the LSB
```

The extracted bit can then be placed at its original position using a left shift:

```c
result = result | (bit << k);
```

After collecting all 8 bits, the original character is reconstructed.

---

## 🧮 Bitwise Operators Used

This project makes use of the following bitwise operators:

| Operator | Purpose |
|----------|---------|
| `&` | Extract a specific bit |
| `|` | Set/store a bit |
| `<<` | Shift a bit to the required position |
| `>>` | Shift bits to the right |

### Example

To extract the LSB:

```c
bit = data & 1;
```

To move a bit to a particular position:

```c
bit << position
```

To combine the bit with the result:

```c
result = result | (bit << position);
```
